🔍 Vérification en base de données

Requête SQL pour vérifier la création des réservations

USE voyageconnect; -- Dernières réservations SELECT r.id, r.reservation_number, r.reservation_type, r.total_amount, r.status, u.email, f.flight_number FROM reservations r JOIN users u ON r.user_id = u.id LEFT JOIN flights f ON r.flight_id = f.id ORDER BY r.created_at DESC LIMIT 10; -- Paiements associés SELECT p.id, p.amount, p.payment_method, p.status, r.reservation_number FROM payments p JOIN reservations r ON p.reservation_id = r.id ORDER BY p.created_at DESC LIMIT 10;

🏗️ Architecture implémentée

URL Méthode Servlet Action
/reservation/new GET ReservationNewServlet Affiche le formulaire de réservation
/reservation/confirm POST ReservationConfirmServlet Crée la réservation en base
/reservation/list GET ReservationServlet Liste les réservations
/reservation/view GET ReservationServlet Détails d'une réservation
/reservation/cancel GET/POST ReservationServlet Annuler une réservation

🔧 Dépannage

Erreur 404 :
  • Vérifier que Tomcat est démarré
  • Vérifier que VoyageConnect.war est déployé
  • Consulter les logs : C:\tomcat2\apache-tomcat-9.0.113\logs\catalina.out
Redirection vers /auth/login :
  • Normal si vous n'êtes pas connecté
  • Utiliser Option A (test-session.jsp) ou Option B (login)
Vol/Hôtel/Circuit introuvable :
  • Vérifier que des données existent en base
  • Modifier les IDs dans les URLs (?id=1, ?id=2, etc.)
  • Exécuter les scripts SQL d'insertion de données de test
