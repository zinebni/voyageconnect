🔄 Flux de Réservation Complet

  1. User se connecte → Session créée avec session.setAttribute("user", userObject)
  2. User clique "Réserver" sur un vol/hôtel/circuit
  3. GET /reservation/new?type=flight&id=1
  4. ReservationNewServlet charge le Flight(id=1) depuis la base
  5. Forward vers form.jsp → Affichage du formulaire
  6. User remplit : nombre de passagers, méthode de paiement
  7. POST /reservation/confirm
  8. ReservationConfirmServlet crée la réservation (transaction JPA)
  9. Forward vers success.jsp → Confirmation
